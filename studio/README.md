# TikTok-студия: 2D-ролики на немецком

## Что здесь
| Папка / файл | Зачем |
|---|---|
| `projekte/<имя>/script.json` | сценарий: сцены с текстом на немецком |
| `tools/make_voice.py` | немецкая озвучка + тайминги для субтитров |
| `video/` | 2D-анимация на Remotion (React → mp4), персонаж, субтитры по словам |
| `make_video.sh` | весь ролик одной командой |
| `out/` | готовые mp4 1080×1920 |

Процесс: **Claude пишет сценарий → озвучка → анимация + субтитры → mp4**. Видеокарта не нужна, 3D не нужно.
Ролик на 1 минуту рендерится примерно за 2 минуты на обычном процессоре.

## 5 плагинов из видео: что нам реально нужно
| Плагин | Для чего он | Нам нужен? |
|---|---|---|
| 1. Free LLM API | переключает модели, когда кончается лимит, при программировании | **Нет**: нам не нужен. Лимит Claude этим не обойти |
| 2. Strix | ищет уязвимости в сайтах | **Нет**: мы не делаем сайты |
| 3. claude-mem | Claude помнит прошлые сессии | **Да, полезно**: нишу, стиль, какие ролики уже вышли. Бесплатная замена: файл `CLAUDE.md` в папке проекта |
| 4. Agent Reach | читает Reddit, X, Instagram, LinkedIn | **Да**: искать темы и тренды |
| 5. Claude Code Setup (Anthropic) | смотрит проект и советует плагины | **Да**: поставить один раз |

**Чего в видео нет, но для роликов это главное:**
- **Remotion** + навык для Claude (`npx skills add remotion-dev/skills`): анимация кодом
- **FFmpeg**: монтаж, склейка, музыка
- **edge-tts**: бесплатные нейроголоса Microsoft, хороший немецкий (`de-DE-ConradNeural`, `de-DE-KatjaNeural`). Нужен интернет
- **Piper**: озвучка без интернета (стоит здесь; голос `thorsten` звучит роботизированно)
- **faster-whisper**: расшифровка и перевод чужих роликов, субтитры
- **yt-dlp**: скачивать ролики-образцы для анализа (не перезаливать: авторские права)

## Установка на твой ПК (Windows)
```
winget install Gyan.FFmpeg
winget install OpenJS.NodeJS.LTS
winget install Python.Python.3.12
pip install edge-tts piper-tts faster-whisper yt-dlp
cd tiktok-studio\video
npm install
npx skills add remotion-dev/skills
```
Хватит 8 ГБ ОЗУ, любого процессора за последние лет 7–8 и Windows 10/11.

## Ниши (немецкий TikTok, роликам нужно больше минуты для монетизации)
1. ⭐ **«Was passiert mit deinem Körper, wenn…»** (тело и наука). Вечные темы, хорошо смотрят до конца, легко рисовать кодом. Пример: демо-ролик.
2. ⭐ **«Was wäre, wenn…»**: «Что если Земля перестанет вращаться», «…исчезнет Луна». Тот же персонаж, бесконечные темы.
3. **Kuriose Geschichte** в 2D: странные факты из истории, в том числе шпионы и война, как в роликах War Zone. ⚠ В Германии запрещена нацистская символика (§86a StGB), и TikTok режет насилие. Подавать нейтрально, без символики.
4. **Психология и деньги**: популярно, но перенасыщено.
5. **Анимированные POV-скетчи**, как у animasinopal: самая высокая вовлечённость, но нужен рисованный персонаж и юмор носителя немецкого. Это сложнее всего.

**Рекомендация:** один канал с одним персонажем-маскотом, совмещающий 1 и 2. Серийный формат («Teil 1, 2, 3…»), 1–2 ролика в день, первые 30 роликов как тест.
